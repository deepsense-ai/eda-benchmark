# deepsense/the-heirs-estate

The agent must trace an ASCII-art family tree (`genealogy_trees.txt`, with
deliberately jagged and fragmented connector lines) to find the
great-great-grandparent of Dawid Majtyka, determine which of that ancestor's
direct children have more than one grandchild, and sum those children's
account balances from `people_accounts.csv` (see
[instruction.md](instruction.md)). The answer is a single integer.
